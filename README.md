# sitsr-media

Immagini e video pubblici usati dai post Instagram di @sitsr.it.

I file sono pubblicati qui solo perché Instagram li scarica da un indirizzo
pubblico al momento della pubblicazione. Testi, piano editoriale e
configurazione stanno nel repository privato InstagramAgent.

- `img/`: immagini (JPEG)
- `video/`: video (MP4)
